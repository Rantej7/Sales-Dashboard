# 📊 Sales Dashboard – Excel, SQL & Power BI

## 📌 Project Overview

This project is an end-to-end **Sales Data Analysis and Dashboard project** using **Excel, SQL, and Microsoft Power BI**. The project involves preparing and analyzing sales data, extracting business insights using SQL, performing analysis in Excel, and presenting the findings through an interactive Power BI dashboard.

## 🎯 Objectives

- Analyze overall sales performance
- Clean and prepare sales data for analysis
- Use SQL to query and analyze sales data
- Perform calculations and analysis using Excel
- Analyze sales trends across different time periods
- Compare sales performance across countries and products
- Build an interactive Power BI dashboard
- Generate meaningful business insights

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data cleaning, analysis, formulas, and reporting
- **SQL** – Data querying, filtering, aggregation, and analysis
- **Microsoft Power BI** – Interactive dashboard and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and analysis
